### 👋 Welcome to my DSA Vault

My personal vault of Data Structures and Algorithms problems. All LeetCode solutions are written in **Java** and are automatically pushed here to track my consistency and coding progress.

### 📌 How It Works

This repository is kept systematic and organized through a clean, automated pipeline:
*   🧑‍💻 **Solve:** I solve algorithmic problems directly on LeetCode.
*   ⚡ **Trigger:** Once the code is 100% accepted, a background extension catches it.
*   📂 **Sync:** The code file and problem details are instantly and securely pushed to this repository.
